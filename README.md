# 🍰 Bolos da Vovó – Totem de Feira

Site usado como totem na Feira de Empreendedorismo, simulando uma loja virtual de bolos para atrair o público.

## 📌 Sobre o Projeto
Apresenta bolos fictícios, carrinho de compras ilustrativo e páginas organizadas com links simulados.

## 🛠️ Tecnologias Utilizadas
- HTML5
- CSS3

## ▶️ Como Usar
Abra `index.html` e explore os produtos. As interações são ilustrativas e não requerem backend.
